# 地质填图系统 — 操作流程

本文档描述地质填图系统从**野外数据采集**到**专业成图**的完整操作流程，适用于实习项目演示与复现。

> 标注 `📸 截图位` 的位置为截图占位，将截图放入 `docs/images/` 后取消注释即可展示。

---

## 一、环境准备

1. 安装 **Python 3.9+**，安装后端依赖：

   ```bash
   cd backend
   pip install -r requirements.txt
   ```

2. 安装 **QGIS 3.22+**（用于插件与成图）。
3. （可选）安装 **.NET 10 SDK** 与 **Visual Studio**（用于 MAUI 客户端）。
4. 配置高德地图密钥（仅导航功能需要）：编辑 `backend/config.py` 的 `AMAP_API_KEY`。

## 二、启动后端服务

```bash
cd backend
python app.py
```

启动成功后，终端显示：

```
  地质填图系统 - Geological Mapping System
  地址: http://0.0.0.0:5050
  桌面端: http://localhost:5050/desktop/
  移动端: http://localhost:5050/mobile/
```

验证服务：

```bash
curl http://localhost:5050/api/health
# {"status":"ok","service":"地质填图系统 API","version":"1.0.0"}
```

## 三、桌面端：数据管理与编绘

浏览器打开 `http://localhost:5050/desktop/`。

### 3.1 创建项目

1. 在「项目管理」中新建项目，填写项目名称、区域、坐标系（默认 WGS84/EPSG:4326，支持 CGCS2000 等）。
2. 每个项目独立管理其地质点、路线、样品、界线、断层、地层面。

### 3.2 导入野外数据

桌面端「数据导入」支持批量上传以下格式：

| 格式 | 说明 |
|---|---|
| Shapefile (.shp + .dbf) | 标准矢量格式 |
| GeoJSON | Web 通用矢量格式 |
| CSV | 表格点数据 |
| KML / GPX | 奥维/手持 GPS 轨迹与点 |

导入时支持**预览模式**（先看前 20 条再确认）与**导入模式**（事务写入，坐标非法自动回滚）。

> 对应接口：`POST /api/sync/import`

📸 截图位：`<!-- ![数据导入与预览](images/desktop-import.png) -->`

### 3.3 编辑地质要素

在地图工作台上可完成：

- **地质点**：添加/编辑观察点、构造测量点、样品点、照片点，录入岩性、地层时代、产状（走向/倾向/倾角）。
- **地质界线**：绘制整合/不整合/侵入/断层接触界线。
- **断层**：绘制正断层/逆断层/平移断层/推覆构造。
- **地层面**：圈定地层单元，填充岩性花纹与颜色。
- **审核**：对采集点进行 `is_checked` 标记。

📸 截图位：`<!-- ![桌面端地图编辑界面](images/desktop-editor.png) -->`

## 四、移动端：野外采集

浏览器打开 `http://localhost:5050/mobile/`（手机可安装为 PWA，或通过 MAUI Android 客户端访问）。

1. 打开移动端，授权 GPS 定位。
2. 新建/选择野外路线，开始**轨迹记录**（自动记录位置、高程、速度、精度）。
3. 沿途添加**地质点**：GPS 自动定位，录入点类型、岩性、地层、产状，现场拍照。
4. 采集**样品**并登记样品编号、类型、采集人。

移动端支持离线缓存（Service Worker），无网环境下先本地暂存，联网后同步。

📸 截图位：`<!-- ![移动端野外采集界面](images/mobile-field.png) -->`

## 五、数据同步

### 5.1 移动端 → 后端

移动端以 JSON 格式批量同步地质点与路线：

```
POST /api/sync/import
Content-Type: application/json
{ "project_id": 1, "points": [...], "routes": [...] }
```

### 5.2 数据完整性检查

```bash
curl http://localhost:5050/api/sync/check-data/1
```

返回缺失坐标、未关联样品/照片、无轨迹路线等问题清单，用于野外归来后的数据自检。

### 5.3 数据状态统计

```bash
curl http://localhost:5050/api/sync/status/1
# { points_total, points_checked, routes_total, photos_total, samples_total }
```

## 六、数据导出

| 格式 | 接口 |
|---|---|
| GeoJSON | `GET /api/export/geojson/<project_id>?type=all` |
| CSV | `GET /api/export/csv/<project_id>` |
| KML | `GET /api/export/kml/<project_id>` |
| Shapefile (ZIP) | `GET /api/export/shapefile/<project_id>` |

坐标转换（支持 CGCS2000 ↔ WGS84 ↔ Web Mercator）：

```
POST /api/export/convert-coords
{ "points": [[116.0, 39.0]], "from_crs": "EPSG:4326", "to_crs": "EPSG:4490" }
```

## 七、QGIS 成图（核心环节）

### 7.1 安装插件

将 `qgis-plugin/` 复制到 QGIS 插件目录并启用，工具栏出现「地质填图」按钮。

### 7.2 导入数据

通过插件或后端导出，将地质点/界线/断层/地层导入 QGIS 图层。

### 7.3 专业编绘

- **地质符号库**：为产状、构造、矿点、采样点配置标准符号。
- **岩性花纹填充**：砂岩、页岩、灰岩、花岗岩等标准岩性花纹。
- **地层界线/断层绘制**：按接触关系（整合/不整合/侵入/断层）规范线型。
- **拓扑检查**：自动检测线断裂、面重叠、悬挂点等拓扑错误。

📸 截图位：`<!-- ![QGIS 成图成果](images/qgis-map.png) -->`

### 7.4 QField 项目导出

插件「QField 导出」一键将 QGIS 项目导出为 QField 兼容格式：

- 图层导出为 **GeoPackage (.gpkg)**；
- 生成 **.qgs** 项目文件 + `qfield_config.json` 配置；
- 内置地质点采集模板（观察点/构造点/样品点/照片点）。

将导出文件夹复制到手机，用 **QField** App 打开 `.qgs` 即可继续野外采集。

## 八、成果归档

野外成图成果（本仓库 `测试数据/`）包括：

- 产状点（构造产状测量结果）
- 地层界限（各组地层分界）
- 地层面（地层单元填充）
- 等高线（抽稀后地形底图）
- 奥维点（奥维地图导出的野外点位）
- 成图（`.mxd` ArcGIS 工程 / `.emf` 矢量成图）

这些成果可在 ArcGIS / QGIS 中直接打开查看。
